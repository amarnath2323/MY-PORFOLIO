# Amarnath M — Animated Portfolio

## Run locally
1. Extract `amarnath_animated_portfolio.zip`.
2. Open the extracted folder.
3. Double-click `index.html`, or open the folder in VS Code and use the Live Server extension.

## Deploy on GitHub Pages
1. Create a GitHub repository and upload `index.html`, `style.css`, and `script.js` to the repository root.
2. Open **Settings → Pages**.
3. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Deploy on Vercel
1. Push the project folder to a GitHub repository.
2. Import that repository into Vercel.
3. Use the project root, with no build command and no output directory needed for this static HTML site.

## Customize
- Edit contact information, project descriptions, education, and certifications in `index.html`.
- Adjust colors, spacing, and responsive layout in `style.css`.
- Edit reveal animations, mobile navigation, active section highlighting, and theme toggle in `script.js`.

The project is plain HTML, CSS, and JavaScript. Google Fonts requires an internet connection; system fallback fonts are included.
